1 Ranks & Build
Core test Every action: 1d10 + Stat + mods vs 7+. Natural 1 always fails, natural 10 always succeeds. The final modifier on any roll cannot exceed +3 / −3.

The pyramid — the only structural rule Exactly one Leader. Every Specialist requires two fighters of lower rank. Every Recruit requires one Fighter or better. Minimum four fighters.
No unit cap The pyramid and budget do it. A Specialist costs exactly two Fighters — the central trade of the system.
Budget Standard = 100 points. (75 = raid · 150 = pitched.)
Loadout Free to every fighter: fists, one Light Melee weapon, thick clothing. Carry limits: one armour · two hands · up to two equipment. Weapons are built (class + characteristics), rank-gated.
Campaign roster Each Advance a fighter carries adds +2 points to its cost; each lasting scar subtracts 2.

6 Deployables — deploy, repair, destroy
Deploy = one INT test 1d10 + INT + Build vs 7+ (spends your Action, place within 1"). Pass → active (mine/trap armed & concealed; hardware online). Fail → placed but exposed & inert (mine armed but visible; hardware Offline). Nat 1 → backfire (trap triggers on the deployer; hardware Destroyed). Nat 10 auto-succeeds.
Build rating (printed on the item)
BuildModFeel
Simple+1wire, spikes — anyone can lay one
Standard0a straight 7+
Complex−1most turrets & beacons
Intricate−2flagship hardware (sniper / burst)
Destruction & repair (standing hardware) WND 1 · Armour −2; cover Heavy (−2) to be hit unless attacker within 6" (then Open). One Injury → Offline. Repair once: adjacent fighter passes an INT test (7+) to bring it back online (Jury-Rig may auto-succeed). Second Injury while Offline → Destroyed. Once placed & spent/destroyed it is gone for the battle, but returns re-armed next battle.
Mines & traps Concealed on a passed deploy (found by Threat Scan / opposed INT). While untriggered they can be shot (Feature damage), disarmed (DEX 7+, nat 1 = boom), or if electronic, Jammed/hacked. Once triggered it is spent — you can't Offline a boom mid-trigger.

7 Infrastructure Features
What it does Infrastructure reshapes the board — routes, sight, cover, elevation. It does not exist to damage models: only two keywords deal harm, and both leave a model Down, never straight Out. Everything starts Powered Down; operating it sets or flips its state, and either crew can flip it back.
FALL Resolve for the height dropped: under 3" nothing · 3"+ Prone · 6"+ Injury roll (+1 Damage per full 2", ignoring Armor).
CRUSH An Injury roll as a hazard: 1d10 + 3 vs 7+, ignoring Armor; a wound → Down (hazard, not Out). Dial to +2 if too lethal.
Categories Mobility new movement Access gate chokepoints Visibility make/remove sight Manipulation move the board Utilities change a zone
The eight board verbs
VerbWhat it does · caught-in-it clause
Open / Close PathToggle an opening passable↔Impassable. Caught model Displaced 1" (heavy door prints CRUSH). Sealed room = all exits Blocked.
Create / Remove RouteAdd/delete a traversal line (bridge, lift, conveyor). Removing an elevated route with a model on it → FALL.
Block / Clear LOSToggle sight; set Concealing / strip Hidden. No model harm.
Create / Remove CoverSet/lift a cover piece or change its value. A model relying on removed cover is now Open.
Shift TerrainSlide a Movable piece up to 4". Model in the path Displaced; pinned against a wall → CRUSH.
Change ElevationRaise/lower a platform, carrying its models. Half-on model steps to nearer level (no FALL under 3").
Field a ZoneApply a Dangerous / Difficult / Impassable overlay via the existing hazard→condition map. Never a new condition.
DisplaceForce-move a model 2" (or 4") from the source. Off a ledge → FALL; into Dangerous → triggers it; Rooted resists (STR).

Hacking a terminal 1d10 + INT − range band vs 7+. Pass → activate one Linked feature now; fail → nothing, terminal stays live. One Action = one hack = one Linked function. No damage roll — controlling the feature is the reward.
Interrupt An enemy in base contact with another live terminal declares Interrupt before the access roll. If the hack would pass, it is jammed and the interrupter's terminal becomes Overloaded (down till start of next turn). If the hack fails, the interrupt is not spent. No opposed roll — bait it with one unit, land the hack with the next.
Linked functions (one per hack) Doors (lock/unlock/open/close) · Cameras (loop/reveal/ignore) · Alarms (suppress/trip) · Power (toggle a system or hazard) · Turrets (rotate/deactivate/fire once = your attack) · Electronic traps (arm/disarm/trigger).

9 Skills — Tier 1 (fieldable now)
How skills unlock Skills ride the stat line: a path-stat at +2 = T1 · +4 = T2 · +6 = T3 (+1 is a dabble, no skill), and each tier a stat reaches grants one skill from that stat's path — so a +4 stat gives its T1 and T2 skill, a +6 gives all three. Counts run ~Fighter 2 · Specialist 3 · Leader 4. The T1 menu below is what most of a crew fields; a Specialist's T2 and a Leader's T3 picks live in the full Skill Paths list. Pick each from its stat's path; modifiers stay conditional, ±3 cap.
