1 Which set do I print?
A single battle Battle set How to Play · Set Up & Scenario · Table References · Unit Cards · Playtest Log. Or just print Kit Bundle — it is all five in one file, print-fitted. Nothing else needed: both players field the same fixed crew.
Testing list building + Crew Builder Add the Crew Builder, one per player. This is the set for Campaign Start @ 500, the least-validated part of the system.
A campaign turn + Campaign Turn + Settlement Sheet Add both, one each per player. The Settlement Sheet is reused every turn; the Campaign Turn sheet is one per turn.
A mini-Season Everything above, plus one Campaign Turn sheet per turn per player. Three battles is enough to see whether the loop holds.

3 What you need at the table
Essential □ 1d10 per player (two is smoother)   □ tape measure in inches   □ a 3'×3' surface   □ 2 crews of 3–6 models   □ terrain for 9–12 large features
Tokens You need markers for Stress (a count), Pinned, Down, Prone, Hidden, Ready, plus Fire/Bleed/Poison. Dice, beads or coins work. A printable set of 85 exists in tts/assets/tokens/.
Terrain is the dial, not decoration Count large features before you start. Density alone swung win rate 66 points in simulation — more than any points cost can. 9–12, one per each of the nine 12" squares, 12 is a hard ceiling. A sparse board hands it to shooters; a crowded one hands it to swarms.
No models or terrain? The Tabletop Simulator table in tts/ is playable now — correct 36×36 board, density-checked terrain, tokens, and chat commands that automate the fiddly bookkeeping.
4 What these tests are actually for
Roughly 6 million games have been simulated against these rules, so the shape is not guesswork. But every number is sim-derived, not table-derived — nobody has played this. The point of a session is not to find out whether it works; it is to find the things a simulation structurally cannot see.
  1. Clock a real 6-round game with 9–12 terrain, Reactions live, and one Event. Target: it should feel like ≤90 minutes. Reactions plus conditions plus Events is where a round inflates.
  2. Campaign Start @ 500. The sim actively contradicts this cap — a rifle-armed Leader plus a rifle Fighter leaves no room for a legal third body. Try to build a shooting crew and see what happens.
  3. Did the Settlement Phase excite you? Every phase should produce at least one purchase you actually wanted. If not, the economy sink problem is confirmed in play.
  4. Dodge. The engine AI cannot stress the escape-LOS case that motivated the half-MOV nerf. Only a table can.
  5. A WND-3 veteran on a kill mission. The sim shows 90%+ wipes; check whether scenario variety already absorbs it.
Fill the Playtest Log during play. The single most useful thing you can record is a moment where you had to stop and argue about what a rule meant — that is a rules defect, and it is invisible to every simulation.
