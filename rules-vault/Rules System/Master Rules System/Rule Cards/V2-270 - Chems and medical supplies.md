# Chems and medical supplies

## Summary

Single-use chems grant +4 to one Stat for the battle; consecutive-battle use causes Addicted.

## Rule text

### Chem limits

Spend Core to administer a dose to yourself or a friendly in contact. The user must be conscious, unpinned, unengaged and allowed to Use Item. A Pinned recipient needs a teammate. A unit may receive one chem dose per round.

Each chem grants +4 to its listed Stat for the rest of the battle. There is one type each for STR, DEX, AGI, INT, NRV and MOVE. Different types can be combined; duplicate bonuses do not stack. Chems do not increase Wounds or unlock skills. Use the normal modifier rules for tests.

Using any chem in each of two consecutive battles causes Addicted for the crew’s next battle. Use the shared Addicted condition for withdrawal and expiry. Medkits, repair packs and antidotes are supplies, not chems.
