# Orders

## Summary

Each Specialist and Veteran receives one Order per battle. The Leader receives one extra. Each Order is single-use and never refreshes.

## Rule text

Each Specialist and Veteran receives **one Order per battle**. The Leader receives one extra. Each Order is single-use and never refreshes.

^orders-allowance

Spend an Order to give ALERT to a friendly unit within 12 inches and line of sight.

^orders-issue

You may issue it during any friendly activation. You may also issue it when that friendly is targeted by an enemy attack or Charge.

^orders-recipient

The recipient may react immediately if eligible. A unit can receive only one Order per round.
