# Battlefield setup and terrain agreement

## Summary

Follow the scenario's terrain selection and layout instructions. Otherwise, use dense, varied terrain suited to the near-future setting. Include cover, terrain that blocks line of sight, firing lanes and flanking routes. Give both crews usable approaches to the objectives.

## Rule text

Follow the scenario's terrain selection and layout instructions. Otherwise, use dense, varied terrain suited to the near-future setting.

^text-s015-b000

Include cover, terrain that blocks line of sight, firing lanes and flanking routes. Give both crews usable approaches to the objectives.

^text-s015-b001

Before deployment, agree each piece's cover, line of sight, movement, climbing and hazard properties.

^text-s015-b002

Identify interactive features, their effects, controls and terminal links.

^text-s015-b003

Objectives must be reachable without a particular skill or item unless the scenario requires it.
