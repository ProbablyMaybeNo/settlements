# Settlements approved rule index

The active index contains the current approved battle-test rules and approved persistent-play foundations. **DRAFTED** means complete enough to test; it does not mean balanced, playtested or final publication text. Catalogue rows come from their individual item owners.

![[Settlements/Rules System/Master Rules System/Settlements Rule Workspace.base#Rule index]]

Use the **Section → Mechanic → Rule** views to browse. Edit the owning card or linked item profile. IDs, anchors and archived feedback remain recoverable.
