# Rule parents — start here

Open [[Settlements Rule Parents.canvas|the parent canvas]]. It shows one card for each Family → Type / Parent pair, grouped into the thirteen rulebook families. Double-click a parent card to open its page and live rule table. Example: **Core Mechanics → Stats → DEX**. Open a listed rule for its full owning text; switch the embedded view to Cards if preferred.

## Assign a rule

1. Open [[Rule Cards - Complete Index#Editable index|Complete Index → Editable index]], or [[Settlements Rule Cards.base#Parent assignments|Parent assignments]].
2. Find the rule and edit its **Type / Parent** cell. Use the exact name of the destination parent, such as Stats.
3. Its parent pages update automatically. The linked index row follows the owning property through Settlements Rule Workspace.

Type / Parent now uses the editable `rule_parent` property on the owning rule card. Its initial value preserves the previous index classification. Catalogue Type (`entry_type`) and Current subsection (`book_subsection`) stay separate, so moving a rule between parents does not turn a weapon into another entry type or rewrite the manuscript.

Family uses the recorded chapter (`book_section`); parents with the same name in different families are separate pages. Planned section remains the separate chapter-layout proposal. Changing a parent does not advance its rule-revision date.

The workspace plugin creates a page and canvas card automatically when a rule is assigned a new parent in an existing family. Keep it enabled. A parent with no remaining rules stays as an empty planning page; personal parent notes and manual canvas positions are preserved. Do not edit a parent page’s identity properties to move its children—change the rules’ Type / Parent assignments instead.

The parent canvas is navigation and visual planning. Dragging a parent card changes its position only; it does not move all its children into another family. The original [[Settlements Rulebook Layout.canvas|all-rule canvas]] retains its separate Planned section behavior.

All current rules, including Deferred material, remain discoverable. Their Status is displayed on the live parent pages. Empty final-rulebook families have labelled placeholders.
