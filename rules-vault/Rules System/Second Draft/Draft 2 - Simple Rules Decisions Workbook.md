# Draft 2 — Simple Rules Decisions Workbook

Use this sheet to decide what the game should do. You do **not** need to write rulebook language or settle edge cases.

## How to fill this in

For each topic, write one of these in the answer space:

- **KEEP** — retain the direction already in the Draft 2 master.
- **CHANGE —** then describe the direction you want in plain language.
- **DEFAULT** — use the simplest workable option.
- **LATER** — leave it out of the first playable version; if a basic game still needs it, use a simple temporary rule.

Short answers are enough. A blank answer means **KEEP** if the master already has a direction; otherwise it means **DEFAULT**. You can answer only a few topics at a time.

When you return this sheet, I will turn the answers into draft rules in one pass. I will not respond with a new questionnaire. I will make routine wording choices and simple defaults myself, then list any important defaults briefly at the end for you to review together.
