# Draft 2 Keywords

Read these with [[Settlements Rules System Version 2]]. The manuscript controls timing and exceptions.

| Term | Current meaning |
| --- | --- |
| Round / Turn / Activation | Six rounds; alternate whole-fighter activations. Each fighter resolves one Move and one Core in either order during its activation; no banking or reactivation. |
| Hands / weapon slots | Two hands give two weapon slots; one-handed uses one, two-handed/Heavy uses two. No weapon needs more than two. |
| Activated | Fighter has taken its one activation this round; clear at Start. Recovery never grants another activation. |
| READY / Reacted | One retained preparation token; spend for one reaction. One reaction per fighter per round, one reacting model per enemy action. |
| Pinned | Ranged hits against it −2; melee hits +2; stack with applicable position modifiers, not Injury. Half-speed crawl, Move Recover, self-Rally or specified Disengage; defensive melee allowed. Base must be visible to shoot it. |
| Recover / Help Recover | Self: Move to stand in place instead of travelling, keeping unused Core. Helper: Core within 3 inches and LOS. Both remove Pinned automatically, not Stress/morale. |
| Aim | Core; +2 next Shoot, including a reaction, through end of next round. Lost on movement/standing, Pinned or engagement; consumed by shot. |
| Down | Zero Wounds; crawl and self-aid only. Record round; one successful revival per battle. |
| Unconscious | Down round +2 at End Phase, or further successful Injury against Down. No revival/actions; remains lootable/carryable. |
| Captured | Secured casualty; no actions, clock continues; escort off own edge for post-battle captivity. |
| Stress | 0–5; ordinary tests/attacks penalised. Injury, Break and Rally ignore it. |
| Broken / Bolting / Bugging Out | Failed Break severity at Stress 1–2 / 3–4 / 5. See the shared morale procedure. |
| Rally | Stress-free NRV; success clears Stress, morale and Pinned. Existing fear uses Rally instead of Break at End Phase. |
| Hidden | Public position, limited targeting beyond 12 inches, −4 when legally targeted, half Move unless Sneak. |
| Marked | Core Mark Target success; +2 friendly shooting, reveal, ends this round. One mark per crew. No wall or Hidden-range bypass. |
| Objective area | Maximum six objectives. 1–3 use 6-inch diameter; 4–6 use 3-inch diameter. The circle is the whole control area, with no extra distance. |
| Claim / Retrieve / Work | Earlier objective procedures retained as Deferred cards; Ross will provide scenario specifics. |
| Unanswered | Defender rolls pool to set maximum but cannot score hits; never automatic hits. |
| Grappled | Specific opposed hold/escape; no human shield or automatic takedown. See Grapple skill. |
| Offline / Destroyed | Device first/second hit; drone first hit destroys. Offline can Repair; Destroyed cannot in battle. |
| Frozen | Terminal unavailable until End Phase; local manual controls remain. |
| Carry / escort | One carrier at half MOVE using its own Move during its activation; one hand, no Dash/Charge. No joint carrying; Strong Arm is a specific speed exception. |
| Crew Rating | Full current Credits value of all fielded people, gear, devices and preparations. Discounts do not reduce it. |
| Settlement round | One management cycle after a qualifying battle, whether or not playing a campaign. |

Weapon traits are defined once in [[Settlements Rules System Version 2#Characteristics]]. Displace, Crush and other terrain effects are defined in [[Settlements Rules System Version 2#13 Interactive terrain catalogue]].
