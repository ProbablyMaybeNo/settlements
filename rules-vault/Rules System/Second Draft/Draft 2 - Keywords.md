# Draft 2 — Keywords

Recorded skill definitions; entries explicitly marked proposed or unresolved remain unfinished. Core rules are in [[Full Rules System v2]].

## UNANSWERED
Use the highest-opposing-total exchange in [[Full Rules System v2#8 · Melee]]. Only the initiating unit can score hits. No automatic return attack.

## DUAL WIELDING
Any unit may attack with two eligible 1 HANDED weapons. Choose a dominant weapon before rolling: use its normal attack dice and one die from the off-hand, without an accuracy penalty. Each die retains its source weapon's damage, traits and range. Combined shooting is one attack and one SHOOT action; target one enemy unless a rule allows splitting. Melee highest-opposing-total resolution and weapon allocation follow [[Full Rules System v2#8 · Melee]].

## AGILE
A weapon with AGILE permits AGI instead of STR for melee. It does not change Damage. This is the current name for the weapon characteristic formerly called Balanced. Ambidextrous requires BOTH weapons to have AGILE; Goliath alone does not supply it.

## AURA
A passive area effect centered on its source. Size determined by source rules. A unit maintains one active aura; it ends when replaced or the source is DOWNED. Big Aura permits two and extends each range by 3 inches. Self-inclusion, LOS and other ending conditions require the shared ruling listed in [[Draft 2 - Progress and Decisions]].

## STRESS TRANSFER
Only transfer Stress that the recipient can actually accept under its maximum. Excess stays on the original unit. Transfer does not create or erase points.

## GRAPPLED
The held unit cannot act or react normally. At the start of its activation, make an opposed STR escape test against the holder; success releases it, failure leaves it held. The holder moves at half MOVE unless Strong Arm applies. Grapple includes Meat Shield: incoming shooting targeting the holder or a friendly within 2 inches requires an unmodified d20 Luck roll, 10+ to hit the intended target, otherwise the held unit. Shooting resolution order and the proposed Crush follow-up are unresolved; see [[Draft 2 - Progress and Decisions]]. No new Luck stat is created.

## STUNNED
Lose current action points and cannot Ready or react until the start of the unit's next activation. This does not itself cancel the next activation's normal refresh.

## FREEZE
A terminal disabled by Interrupt cannot be used until the end of the next turn. This affects the ENEMY terminal; the source terminal is not automatically overloaded. Shared turn/round terminology still requires confirmation.

## UNCONTESTED
Reserved keyword for Tagged. The proposed meaning is no enemy within objective control range; Ross required a shared keyword entry but has not finalised that definition. Until ruled, agree the interpretation before using Tagged.

## PINNED / RECOVER
Only MOVE (half speed) and RECOVER are permitted while Pinned. Recover spends a Core Action and removes Pinned, not Stress or a break condition. Recover before moving to use normal MOVE, or move at half speed before recovering. Forced Bolt/Bugging Out overrides this movement restriction. See [[Full Rules System v2#10 · Conditions]].

*A UNIT MOVING WHILE PINNED CAN ONLY BE TARGETED BY RANG*

## BREAK / RALLY
See [[Full Rules System v2#11 · Morale]]. Both use d20 + NRV vs 15+ with applicable non-Stress modifiers; neither subtracts Stress. Failed Break severity uses Stress: 1–2 Broken, 3–4 Bolting, 5+ Bugging Out. Failed Rally retains the existing condition. Use [[Draft 2 - Simulation Assumptions]] for next-pass edge cases.
