# Reactions and interruption

## Summary

Reaction timing; Reaction limits; Reaction Shoot; Return Fire; Dive; Operate reaction; Interrupted action; Incoming shooting window

## Rule text

### Reaction timing

After an enemy declares an action, before that action resolves, the non-active player may declare **one reaction by one model**. Reaction Shoot is available at the start or end of a non-shooting enemy action. If an enemy Shoot targets a different fighter and does not target the reacting fighter, Reaction Shoot is available only at the end, after all outcomes of that Shoot have been resolved. Check the reacting model's READY, reaction eligibility, forward arc, line of sight, and range at the chosen endpoint. Reaction Shoot cannot be declared at an intermediate movement point. Other reactions retain the option to wait for a visible point along a declared movement path or the end of the action, subject to their own printed timing; announce the precise point before the model moves past it. The entire action, including a Charge's movement and attack, allows only one reacting model, even if several are eligible.

^text-s021-b000

### Reaction limits

Spend READY immediately and mark Reacted. No reaction triggers another reaction. Devices' automatic mine triggers are hazards, not reactions; a sentry turret's shot is a reaction and uses the same one-model limit.

^text-s021-b002

### Reaction Shoot

| Field | Value |
| --- | --- |
| Reaction | Shoot |
| Resolution | Fire at the triggering enemy using the normal shooting rules at the start or end of each enemy non-shooting action. If an enemy Shoot targets a different fighter and does not target the reacting fighter, ordinary Reaction Shoot is also available at the end of that Shoot, after all enemy attack outcomes have been resolved. Start is after action declaration but before resolution; end is after that action is completed. At the chosen endpoint, check READY, normal reaction eligibility, line of sight within the reacting fighter's forward arc, and weapon range. Do not nominate an intermediate movement point. A start reaction may interrupt an unfinished action under the interruption rules. An end reaction cannot cancel or undo the completed action. Resolve or forfeit any remaining unused slot in the same activation according to the acting fighter's resulting state. |

^text-s021-b003

### Return Fire

| Field | Value |
| --- | --- |
| Reaction | Return Fire |
| Resolution | If the triggering enemy is shooting you and is a legal target, declare Return Fire before any attack dice are rolled. Both fighters shoot using independent normal 13+ shooting tests. Resolve both attacks from the positions and states at declaration, then apply both sets of outcomes. Both fighters can hit and be injured; complete the exchange even if one shooter is Downed by it. |

^text-s021-b004

### Dive

| Field | Value |
| --- | --- |
| Reaction | Dive |
| Resolution | Before an incoming shot or Charge, test AGI. Pass: move up to 3 inches to a legal position and become Pinned; fail: stay and become Pinned. Recheck the declared attack's range and LOS. This is diving before the shot, not dodging a bullet already rolled. |

^text-s021-b005

### Operate reaction

| Field | Value |
| --- | --- |
| Reaction | Operate |
| Resolution | Use a control or terminal you can currently reach. Resolve one legal terrain operation before the trigger completes. |

^text-s021-b006

### Interrupted action

A hit that Pins or Downs the acting fighter cancels its unfinished action and consumes the slots spent. If a moving fighter is interrupted, it stops at that point. Resolve or forfeit any other unused slot within the same activation according to the fighter's new state; a cancelled action is not refunded. A cancelled Charge has no attack. An operation that closes a route stops movement at the obstruction; it does not allow the remaining distance to pass through it. A simultaneous Return Fire exchange is completed even if one shooter is Downed by that exchange.

^text-s021-b008

### Incoming shooting window

For an incoming Shoot that targets the reacting fighter, Return Fire or Dive must be declared before any attack dice are rolled. Waiting until its end does not permit retroactive Return Fire or evasion. If the enemy instead shoots a different fighter and does not target the reactor, ordinary Reaction Shoot may be declared at the end of that Shoot, after all attack outcomes have been resolved. Check the reactor's READY, reaction eligibility, forward arc, line of sight, and range at that point.

^text-s021-b001
