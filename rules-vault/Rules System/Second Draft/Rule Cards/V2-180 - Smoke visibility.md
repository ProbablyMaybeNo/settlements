# Smoke visibility

## Summary

Blocks LOS up to 3″ above surface; models inside see/be seen only within 1″.

## Rule text

**Fall:** use [[Settlements/Rules System/Second Draft/Settlements Rules System Version 2#7 Movement facing and visibility|movement facing and visibility]]. **Smoke:** blocks LOS through the template at any height up to 3 inches above its surface; fighters inside can see and be seen only within 1 inch. **Difficult:** movement costs double. Only the named state persists; do not add new conditions for individual machines.
