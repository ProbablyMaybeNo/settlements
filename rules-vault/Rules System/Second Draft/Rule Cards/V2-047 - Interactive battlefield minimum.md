# Interactive battlefield minimum

## Summary

Four interactive features beyond doors; three operation types; two change objective routes/LOS; at least two terminals.

## Rule text

Add **four interactive features beyond ordinary doors**, using at least three different operations from [[Settlements/Rules System/Second Draft/Settlements Rules System Version 2#13 Interactive terrain catalogue|interactive terrain catalogue]]. At least two must change routes or visibility around objectives. Provide at least two terminals, each linked to one or more of these features. Place controls so both crews can reasonably reach them. Mark all links openly. No hacking-only objective is required in the standard mission builder.
