# Fight and opposing pools

## Summary

Core; each die exceeding enemy's highest total hits. Equal maxima cause no hits; only one side scores.

## Rule text

Melee compares attack pools rather than single tests. The complete procedure is in [[Settlements/Rules System/Second Draft/Settlements Rules System Version 2#8 Shooting and close combat|shooting and close combat]]. Do not pair dice, subtract enemy stats, or count ordinary test successes in a melee exchange.

^text-s008-b000

Each die whose total **exceeds the opponent's highest total** scores a hit. Equal highest totals cause no hits. Only one side can score hits in an ordinary exchange. Roll Injury for those hits; there is no automatic second attack-back.
