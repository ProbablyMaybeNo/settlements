# Interact and stat examples

## Summary

Interact. Spend a Core action to operate an object or feature. You normally need base contact and cannot be engaged.

## Rule text

**Interact.** Spend a Core action to operate an object or feature. You normally need base contact and cannot be engaged.

^text-s019-b010

Trivial operations succeed automatically. Difficult, contested or dangerous work uses an ordinary Stat test.

^text-s049-b000

If an operation threatens an occupied space, the operator must test first. A successful operation then gives affected units the feature's stated escape chance.

^text-s049-b001

Use STR for force, DEX for manipulation, INT for technical work, AGI for traversal and evasion, and NRV for composure. Failure has the printed consequence. Do not add difficulty tiers.

^text-s049-b007

Disarming a device specifically uses INT, as stated in the Device rules.
