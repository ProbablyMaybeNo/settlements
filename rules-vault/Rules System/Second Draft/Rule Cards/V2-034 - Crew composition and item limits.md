# Crew composition and item limits

## Summary

When creating a crew, include exactly one Veteran. For each Specialist, include at least two Recruits or Fighters in any combination. The Veteran does not count towards this requirement. These restrictions apply when the crew is first created.

## Rule text

When creating a crew, include exactly one Veteran. For each Specialist, include at least two Recruits or Fighters in any combination.

^text-s011-b000

The Veteran does not count towards this requirement. These restrictions apply when the crew is first created.

^text-s011-b002

Before each battle, nominate one fielded Veteran as Leader.

^text-s011-b001

A later crew may field several Veterans, but only one is its Leader. Use the Orders rules for their allowances.
