# Components, models and templates

## Summary

You need miniatures, rosters, d20s, a d6, a d10, measuring tape and state markers.

## Rule text

You need miniatures, rosters, d20s, a d6, a d10, measuring tape and state markers.

^text-s003-b000

Human models normally use 28 mm bases.

^text-s003-b001

Mark each base's forward 180-degree arc. Agree proxies and unusual sizes before deployment.

^text-s003-b003

Use circles with 3-inch and 5-inch diameters and an 8-inch teardrop template.

^text-s003-b005

Each weapon or effect states which template to use.

^text-s003-b002

Follow the Game setup checklist to prepare a battle.
