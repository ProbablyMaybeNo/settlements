# Dive

## Summary

Before Shoot/Charge, AGI test: pass moves up to 3″; either result Pins. Recheck attack LOS/range.

## Rule text

| Field | Value |
| --- | --- |
| Reaction | Dive |
| Resolution | Before an incoming shot or Charge, test AGI. Pass: move up to 3 inches to a legal position and become Pinned; fail: stay and become Pinned. Recheck the declared attack's range and LOS. This is diving before the shot, not dodging a bullet already rolled. |
