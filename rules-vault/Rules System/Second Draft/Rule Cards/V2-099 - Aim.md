# Aim

## Summary

Core; +2 next Shoot, including reaction, through next round. Lost on movement/standing, Pinned or engagement.

## Rule text

| Field | Value |
| --- | --- |
| Action | Aim |
| Cost | Core |
| Main effect | Prepare +2 on your next Shoot, lasting through the end of next round; lost if you move or become Pinned first |

^text-s019-b002

Aim costs Core and gives +2 to the next Shoot, including a shooting reaction. It lasts through the end of the following round, but is lost earlier if the fighter moves, stands up, becomes Pinned, or enters engagement. Apply it to the whole shot, then remove it. Repeated Aim does not stack.

^text-s029-b001
