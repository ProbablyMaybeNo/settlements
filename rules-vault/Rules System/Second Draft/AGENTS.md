# Settlements active workspace — 2026-10-25

Start with [[Settlements/START HERE - Settlements Project]] and [[Settlements/Rules System/Second Draft/Rule Cards - Complete Index]]. The official Rule Cards/ folder contains 82 consolidated procedure/catalogue cards. Item Cards/ holds 193 individual entries in 16 type folders (Weapon Cards, Skill Cards, Equipment Cards, etc.), excluded from the official index. Eighteen historical objective/scenario proposals remain in Deferred Rule Cards/, outside the index. These counts describe the 2026-10-25 migration; later approved additions may change them.

Hierarchy is Section → Mechanic → specific rules. Section uses `book_section` (formerly displayed as Family), Mechanic uses `rule_parent` (formerly displayed as Parent). Keep the existing Base view names and parent canvas. The official index, progress boards and contextual tables use Settlements Rule Workspace.base; Item Card Library.base is a separate item library, not another rule inventory.

Procedure text is owned by Rule Cards/; item Rule text is owned by Item Cards/<kind> Cards/. Twenty-one official catalogue tables are generated from item Rule text by Settlements Rule Workspace 1.2.0. Edit linked item cards rather than generated catalogue rows; synchronize visible Summary and `summary` after a semantic edit. New items need unique V2 IDs, item type/kind metadata, and membership in their catalogue's `catalogue_members`. Keep all IDs/anchors. Consolidated procedure cards preserve original per-rule statuses, dates and feedback in `component_rules`; those records are provenance, not a second editable rules source. Update the component record only when explicitly revising that component's approval/date. Catalogue status rolls up item statuses; hybrid cards also include `procedure_status`.

Status values are Pending, Partial, Drafted, Confirmed, Locked, Deferred. Organization changes never advance `last_rule_update` or imply confirmation. Semantic changes update owning Rule text, summary/profile properties and Pacific semantic date. Preserve unknown dates. Progress totals count official cards; catalogue progress reflects item dependencies and does not approve an item automatically. Preserve personal notes outside generated markers. Parent Canvas uses #^parent-summary blocks; canvas moves are visual only.

The manuscript, Rulebook Sections/ and Rule Text Assemblies/ are reading views with live embeds. The complete original 483-card snapshot is in Archive/Settlements/2026-10-25 - Rule card consolidation/ outside the active project. Earlier retired organization remains under the 2026-10-24 archive. Do not regenerate legacy catalogues, canvases, static inventories or review tables. Edit the live vault, then mirror with scripts/sync-rules.ps1. Existing simulations are historical, not validation of current rules.
