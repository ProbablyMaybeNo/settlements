# Settlements — Rule index

The single live index of every current rule card. Edit Status, Parent, description, tags or Notes in the table. Click a name for the owning rule text. Family groups and Parent sorting provide the hierarchy.

![[Settlements/Rules System/Second Draft/Settlements Rule Workspace.base#Rule index]]

## Status

| Status | Meaning |
| --- | --- |
| Pending | Not written. |
| Partial | Partly written; not functional yet. |
| Drafted | Written; awaiting confirmation. |
| Confirmed | Confirmed; awaiting final text review. |
| Locked | Final text ready for the rulebook. |
| Deferred | Outside the first rulebook; retained for possible future updates. |

**Updated** is the owning card’s `last_rule_update`, not its filesystem timestamp. Status, parent and other housekeeping changes do not advance it. Blank means unknown.
