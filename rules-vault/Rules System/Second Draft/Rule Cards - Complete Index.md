
 
 
 # Settlements — Rule index

The single live index of **82 official rule cards**. Follow **Section → Mechanic → specific rules**: sections group the table, mechanics organize the cards, and each card contains its specific rules or catalogue table. Edit Status, Mechanic, description, tags or Notes here.

Weapons, skills, equipment and other entries have **193 separate individual cards** in the [[Settlements/Rules System/Second Draft/Item Cards - Library|item card library]]. They are excluded from this list. Open a catalogue for its complete table; click an item name to open its individual card. The 18 deferred proposals remain outside this index.

## Status

| Status | Meaning |
| --- | --- |
| Pending | Not written. |
| Partial | Partly written; not functional yet. |
| Drafted | Written; awaiting confirmation. |
| Confirmed | Confirmed; awaiting final text review. |
| Locked | Final text ready for the rulebook. |
| Deferred | Outside the first rulebook; retained for possible future updates. |

**Updated** is the owning card’s `last_rule_update`, not its filesystem timestamp. Status, parent and other housekeeping changes do not advance it. Blank means unknown.
