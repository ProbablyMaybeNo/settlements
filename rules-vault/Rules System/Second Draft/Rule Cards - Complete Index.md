# Complete Rule-Card Index

**483 active-library cards.** Includes deferred objective proposals. Removed rules are recorded in [[Draft 2 - Progress and Decisions#Confirmed follow-up decisions - 2026-10-19|the dated decision record]].

**Last updated** is the confirmed rule-text revision date in Pacific time (`America/Los_Angeles`); blank means unknown or not yet recorded. It mirrors each owning card's `last_rule_update`, not its filesystem timestamp.

## Editable index

Change **Type / Parent** in this live table to reassign a rule. Open a parent on [[Settlements Rule Parents.canvas|the parent canvas]] to see its automatically filtered rule list. Status and other editable properties are also stored on the owning cards. The chapter tables below remain linked mirrors.

## Rule status

| Status | Meaning |
| --- | --- |
| Pending | Not written yet. |
| Partial | Partially written; not yet functional. |
| Drafted | Written; awaiting confirmation. |
| Confirmed | Written and confirmed; awaiting final text review. |
| Locked | Final text complete; ready for the rulebook. |
| Deferred | Outside the first rulebook; retained for possible supplements or updates. |

Edit **Status** (`status`) on the individual card or in [[Settlements Rule Cards.base|the Rules table]]. The local Settlements Rule Workspace plugin mirrors it into this index, including changes made while Obsidian was closed when the plugin next loads. **Ctrl+P → Settlements Rule Workspace: Refresh rule statuses in the complete index** also refreshes it. This column is a mirror: edit the owning card, rather than typing a different status into this index.

**Review flag** (`review_status`, such as Needs review) remains separate. **Scope** (`publication`) follows Status: Deferred excludes the card from included-only views; all other stages use Included. Change Status to defer or restore a card. Neither status changes nor review flags change the rule-text revision date. Locked means text-ready, not playtested balance.

Initial classification on 2026-10-24 carries existing authored proposals forward as Drafted, preserves the two confirmed objective conventions as Confirmed, and preserves eighteen deferred proposals. Five weapon profiles without required template assignments/procedure are Partial (V2-259, V2-260, V2-300, V2-301, V2-302). No card is automatically Locked. This is a migration of recorded progress, not a fresh audit or confirmation of every mechanic.

## Rule hierarchy

Read the hierarchy as **Family → Type / Parent → Rule**, for example **Core Mechanics → Stats → DEX**. Family comes from the card’s recorded rulebook chapter (`book_section`). Type / Parent uses the editable `rule_parent` assignment, initially seeded from the catalogue type (Stats, Weapons, Skills, etc.) or ordinary-rule subsection. Changing it in the Editable index updates parent-page membership without rewriting rule text or the current subsection. Planned section remains a separate layout proposal until applied to the manuscript. These columns describe existing placement; they do not move or rewrite rules.
