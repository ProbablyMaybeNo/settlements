# Settlements Version 2 — Rules and Mechanics Review

**Write your feedback in the Notes column.** Each row is one rule, procedure, state, skill, item, or structure in [[Settlements Rules System Version 2]]. Its full-text link opens its individual rule card, with full text, shared context and source links. Stable **V2-###** references identify your comments even if rows move.

This is a concise review index, not replacement rules text. Limits, exceptions and complete costs remain in the linked section. The manuscript remains a working proposal; inclusion here does not mean a rule is separately approved or playtested. Your October 18 hand-capacity and whole-unit activation rulings are integrated. Crossed-out passages are excluded; where their mechanics remain elsewhere, the row links to that surviving rule.

**Tags:** use Find (`Ctrl+F`) to jump between matching tags; these same labels can become row filters in Fibery. Useful searches: `#combat`, `#hit-plus`, `#hit-minus`, `#armour-plus`, `#damage-plus`, `#movement`, `#terrain`, `#skill`, `#settlement`, `#review`. Tags describe the mechanic's effect, not approval status. A normal Markdown table stays directly editable; no automatic row filtering is implied.

**Feedback:** write freely, or start a note with **KEEP**, **CHANGE**, **REMOVE**, or **QUESTION**. Refer to another row by its V2 number when rules interact. I will read those notes, amend the owning card’s rule text, propagate the change, and update this summary while preserving your notes. An empty Notes cell is not approval. Do not regenerate this table over annotated rows.

**Pending details:** template dimensions differ between Components and the attack rules; affected entries carry `#review`. Carrying is resolved: one carrier at half speed, with the existing Strong Arm skill exception.

**Reading shorthand:** Cr = Credits; Mat = Materials; Dmg = Damage; ″ = inches. Prices and profiles are provisional. `#review` identifies an unresolved detail in the existing text, not a new mechanic.


**Coverage: 483 entries**, in rulebook order. Full catalogue entries are included so individual skills, gear, terrain and structures can receive their own feedback.

**Last updated** records the last confirmed rule-text change, dated in Pacific time (`America/Los_Angeles`). Blank means unknown or not yet recorded; file modification dates and housekeeping are not rule revisions. This column mirrors the owning card's `last_rule_update` property.

## Scope and later updates

The table covers the current playing and persistence rules, plus each named catalogue entry. Worked examples repeat those mechanics and have not been counted again. Lore, factions, fiction, publication material, linked campaigns and authored scenarios remain placeholders; see [[Settlements Rules System Version 2#24 Campaign and scenario content]]. Roster bookkeeping is included. Archived drafts and old simulations supply no additional rules to this table.

For later additions, use a new unused V2 reference; never renumber existing entries or discard Notes. Update rule text first, then its linked summary. If a rule is removed, preserve its annotated row with a removal note until your feedback has been addressed.
