# Individual item cards

Weapon Cards, Skill Cards, Equipment Cards and the other catalogue entries live here. They are separate from the official rules index. Use the view selector for a particular card type.

![[Settlements/Rules System/Second Draft/Item Card Library.base#All item cards]]

Edit an item's **Rule text** in its individual card. The workspace plugin refreshes its catalogue table and derived profile properties automatically. Edit item Status here to update catalogue progress; no rule date changes for organization or status edits.
