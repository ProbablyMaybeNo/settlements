# Decoy mine

## Summary

Deploy three face-down mine tokens within 6 inches: two X tokens and one live token. A unit entering within 3 inches triggers and reveals that token. An X does nothing. The live token detonates with a 3-inch-diameter Blast at Damage 1; remove all remaining tokens. The set counts as one active field deployable.
