# Trauma Reset

As an Action beside a Down fighter with medical supplies, pass an INT test **at −3** to restore them to 1 WND, remove Down and remove one of Bleed, Poison, Blind or Shocked. Each casualty can benefit once per encounter. *(Medic · Recovery support)*
