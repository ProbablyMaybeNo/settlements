# Master the Moment

Once per game when you issue an Order, apply it to two eligible allies instead of one. Neither granted Action or Reaction can issue an Order. *(Leader · Order specialist)*

*Record. These properties are the source of truth — `records.py` regenerates the table in [[Skill Paths]] from them.*
