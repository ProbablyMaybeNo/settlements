# Archived Rules System Material

This folder contains superseded rules and design notes retained for historical reference. Archived material is not part of the live Settlements rules and must not be used to resolve a conflict with [[Full Rules System v1]] or the current design notes.

## Archived on 2026-09-19

- [[Weapons — superseded 2026-09-19]] — the previous weapon construction note, replaced by [[Basic Weapon System]]. It retained the earlier fixed class structure, legacy characteristics, measured-price notes, and sample armoury.

When a future system replaces a live note, move the old note here, preserve its original text, add the superseded date to its filename, and link the replacement from the relevant live note and [[Rules System MOC]]. Do not delete historical rules merely because they are no longer active.
