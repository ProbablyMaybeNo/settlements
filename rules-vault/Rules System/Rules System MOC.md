> **How to use this**
> - **Canvas** = spatial board. Columns are build stages (S1→S6). Arrows are *depends-on*. Move nodes freely; open a card to edit — changes live in the notes.
> - **Graph view** (Ctrl/Cmd-G) = auto-web of every `[[link]]`, including the rule-ledger links the canvas keeps tidy.
> - Each phase note has `depends_on` / `feeds_into` in its frontmatter, so you can also drive Dataview/Bases views off it later.
