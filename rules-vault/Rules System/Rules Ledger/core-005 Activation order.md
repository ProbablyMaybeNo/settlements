# core-005 · Activation order
> **core** · status **draft** · v0.1

**Parent phase:** [[Initiative & Activation]]

## Text
- **Round:** Priority → alternating activations → End Phase.
- **Priority:** both roll `1d10` (+1 if fewer surviving models). Winner chooses to go first or second. Ties re-roll.
- **Activation:** one unit — **Move slot + Action slot** (or Sprint / Charge consuming both). One attack per activation.
- **Orders:** Recruit 0 · Specialist 1 · Leader 2 — free Action or Reaction to self or ally; cannot chain.
- **Ready / Reaction:** spend Action (or Order) to react once when an enemy enters LOS or takes an exposed action. Options named: Snap Shot, Charge, Throw, Interact, Trigger *(resolutions TBD)*.
