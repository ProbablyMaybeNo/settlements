# Defence-only melee

Both units roll melee pools against 13+. Normal successes cancel normals; critical successes cancel criticals. Only the initiating attacker’s remaining successes become hits. Surplus defence does nothing and causes no Stress. A specific skill may grant a counterattack.

This restores Ross’s intended attacker advantage without adopting the suggested generic +2 initiative bonus. Charge retains its existing bonus. Ordinary melee, the working reference and the ChatGPT working list use this same procedure. Unanswered remains a compatible label in skill references, not an additional permission to harm the defender.

No balance simulation was run.
