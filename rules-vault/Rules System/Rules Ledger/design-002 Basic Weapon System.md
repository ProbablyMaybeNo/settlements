# design-002 · Basic Weapon System

Recorded 2026-09-19. Current wording: [[Basic Weapon System]]. Stable entry point: [[Weapons]].

The current basic weapon system uses seven classes: Unarmed, 1h Ranged / Sidearm, 2h Ranged, Heavy 2h Ranged, 1h Melee, 2h Melee, and Thrown. Classes provide envelopes; named weapons are assembled from class values plus characteristics and drawbacks.

Heavy 2h Ranged is Specialist-gated. A sniper rifle has no additional Specialist or Leader gate beyond its class. Reach and Deadly / Automatic Down are not basic characteristics. Accurate and Precision remain separate, intentionally overlapping accuracy options. Reload costs one Action before the weapon can fire again.

The former weapon construction note is archived at [[Archived/Weapons — superseded 2026-09-19]]. Existing Attack Dice, Damage, Conditions, and costing rules remain governed by the master rules until each value is deliberately propagated into the new named catalogue.
