# Version 2 concise rules review table

Ross requested a concise, scannable Obsidian table covering all current Version 2 rules/mechanics, with names, categories, filtering tags, short descriptions and full-text links. [[Settlements Rules System Version 2 - Rules and Mechanics Review]] contains 453 entries and an additional Notes column for feedback.

Entries include every named skill, weapon profile, weapon characteristic, equipment item, deployable, terrain feature, settlement structure and injury outcome, plus core procedures and roster bookkeeping. Each has a stable V2 reference. Worked examples are not duplicate mechanics; crossed-out source prose and presentation/campaign placeholders are excluded. Surviving rules elsewhere in the manuscript remain included.

The live master remains the rules authority. Entries summarize proposals without converting them into approved or playtested rules. Ross's October 18 activation and hands corrections are integrated; see [[design-007 Whole-unit activations and weapon hands]]. The template discrepancy remains flagged for review. Ross subsequently chose one carrier at half speed; V2-091 now records the single-carrier rule, preserving its ID and Notes. The existing Strong Arm skill exception remains.

Feedback is intended to update the master first, then propagate to references and these summaries. Preserve IDs and Notes on every future update. Empty feedback is not approval. The table is editable Markdown; tags support Find now and can become row filters when imported to Fibery. No Fibery import was requested or performed.

Coverage and link checks are recorded in `docs/draft2-review-table-2026-10-18/coverage.json` and `validation.json`. This is document validation only; no battle simulation or playtest was run.
