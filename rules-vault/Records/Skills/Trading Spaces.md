# Trading Spaces

After winning a melee attack, before the Injury roll, exchange base positions with the defender if both bases fit. This does not trigger Disengage. *(Controller · Mobile melee)*

*Record. These properties are the source of truth — `records.py` regenerates the table in [[Skill Paths]] from them.*
