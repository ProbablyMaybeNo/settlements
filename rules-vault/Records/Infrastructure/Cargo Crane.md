# Cargo Crane

*Manipulation · Shift Terrain / Create-Remove Cover / Displace*. The signature piece. Move a Movable piece up to 4" (open a lane, drop a crate as **Heavy cover**, or lift cover away). Drop a load on a model → **CRUSH**; sweep a model → **Displace 2"** (off a ledge → **FALL**). Carry a junked car between rooftops to make a shielded crossing.
