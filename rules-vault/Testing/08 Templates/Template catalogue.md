# Template catalogue

## Summary

Copy a template only when there is a real session, observation, issue or decision.

^testing-summary

- [[Settlements/Testing/08 Templates/Session template|Session template]] - narrative and evidence links for one actual session.
- [[Settlements/Testing/08 Templates/Issue template|Issue template]] - one concern with evidence, alternatives and impact.
- [[Settlements/Testing/08 Templates/Decision and retest template|Decision and retest template]] - an explicit decision and its verification.
- [[Settlements/Testing/08 Templates/Test brief template|Test brief template]] - a planned question, method and recording scope.

Replace placeholder identifiers. Template files are excluded from actual session counts. Do not mark a proposed change approved or a planned retest passed.
